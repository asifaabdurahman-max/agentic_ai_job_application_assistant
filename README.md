# Agentic AI Job Application Assistant

## Overview
A Python-based project that helps candidates analyze job requirements, compare skills with a resume, identify skill gaps, and prepare for interviews.

## Features
- Job description skill analysis
- Resume skill analysis
- Skill matching and match percentage
- Missing skill identification
- Personalized learning plan
- Interview question generation
- Downloadable text report

## Technologies Used
- Python
- Google Colab
- Regular Expressions
- Python Lists and Dictionaries

## How It Works
1. The user provides a job description and resume text.
2. The assistant identifies skills using a predefined keyword list.
3. It compares required skills with candidate skills.
4. It calculates a skill match percentage.
5. It creates a learning plan for missing skills.
6. It generates interview practice questions.
7. It exports the results to a text file.

## Limitations
Skill extraction uses predefined keywords and may miss relevant skills or misunderstand context. The match percentage is not a validated measure of job suitability. Interview questions are generated using predefined templates.

## Future Improvements
